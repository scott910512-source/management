버전 컨셉 · 기술 배경

v1 재고 기반 위에 합성 배치 전체 흐름(제품→BOM→일괄처리)을 완성하고, 유해화학물질 월별·일별 대장·종합현황 대시보드·월간 보고서까지 확장. 단순 재고 관리에서 공장 운영 전반을 커버하는 시스템으로 진화.

v2 신규 테이블
batches합성 Batch — 제품+연도+번호로 식별. 같은 제품+번호면 합성시작일 공유
boms제품별 BOM — 품목그룹 단위 Batch당 원·부재료 사용 기준량
products제품(사용처) 마스터 — BOM·배치의 기준 제품 목록
recurring_tasks정기(반복) 업무 템플릿 — 일/주/월 주기마다 Task 자동 생성
hazardous_ledger유해화학물질 일자별 관리대장 수동 입력 — 수불 자동집계 보완

주요 구현 기능

v2에서 새로 추가·강화된 기능

제품 마스터 + BOM
제품(사용처) 마스터 등록. 품목그룹 단위 Batch당 기준량 설정. 투입 시 BOM 자동 계산
배치 일괄 처리
FIFO 자동 + 직접 지정 혼합 출고. Lot 다수 선택(취합). 출고 Lot 목록 표시. 퀵메뉴 바로 열기
품목그룹 관리
원·부재료 제품명 그룹화. 그룹 단위 BOM. 비고=가장 오래된 Lot. Total=pkg수량/총수량
정기(반복) 업무
recurring_tasks 템플릿에 일/주/월 설정. 서버 기동 시 누락 Task 자동 생성
유해화학물질 대장
월별·일별 관리대장 자동 집계. 수동 정정. 품목별 탭 + 그룹집계. 보관한도 경고
종합현황 고도화
경고 원통 롤업 애니메이션. 가로 3분할 레이아웃. Canister 제품명 합계. 재고신호등
월간 보고서
관리자 HTML 보고서. 안전재고·유해초과 판정(월중 1회라도 발생). 품목별 재고 그래프

기능 강화 · 인터락

v2에서 추가된 데이터 정합성 보장 구조

배치 삭제 원복
배치 삭제 시 출고 수불 역방향 재삽입(출고→가산). 재고 자동 원복
수불 삭제 원복
수불 직접 삭제 시에도 동일 원복 로직 일관 적용
품목그룹 필수화
BOM 설정·배치 처리 시 품목그룹 필수 지정. 그룹 없는 배치 방지
투입이력 일원화
원·부재료 일괄 출고 버튼 제거 → 배치 일괄처리로 통합. 중복 경로 제거

버그 수정 · 원인 분석

v2 개발 중 발생한 주요 버그와 해결

배치 처리 수량 오류
FIFO+직접 지정 혼합 시 수량 계산 오류 → Lot별 처리 순서 재설계
배치 삭제 미원복
배치 삭제 시 재고 원복 누락 → 삭제 전 역방향 수불 삽입
수불 삭제 미원복
수불 직접 삭제 시 원복 누락 → 배치와 동일한 역방향 처리 일관 적용
보고서 재고 역산
기준월 말 시점 재고를 수불 역산으로 계산. 지난달=월말·당월=현재 명확화

학습 · 기술 포인트

v2에서 익힌 핵심 기술 개념

이벤트 소싱 vs 직접 차감
Lot 잔량 직접 차감 + 수불 이력 별도 보관. 삭제 시 역방향 수불로 정합성 유지
BOM 기반 자동화
제품→품목그룹→BOM 3단계 계층. 배치 처리 시 기준량 자동 적용으로 수기 오류 제거
