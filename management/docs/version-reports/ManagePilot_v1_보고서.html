버전 컨셉 · 기술 배경

StockPilot 경험을 바탕으로 공장 환경에 맞는 멀티 공장·Canister·배치·업무 통합 관리 시스템을 DB 없이 구축. 폐쇄망 VDI에서 더블클릭 한 번으로 실행 가능한 구조.

기술 스택 & 데이터 구조
React 18 + Vite자체 디자인 시스템 — 외부 UI 라이브러리 없음. 애플 스타일 카드 레이아웃
Express 4000REST API. session 인증, 미들웨어 기반 공장(plant) 컨텍스트 분리
CSV + withLock파일별 비동기 뮤텍스로 동시 쓰기 충돌 방지. 공장별 하위 폴더 저장
start-server.bat더블클릭으로 서버 실행. Node.js만 설치하면 폐쇄망 즉시 운영
멀티 공장1공장·2공장 데이터 완전 분리. plantScope(all|특정공장) 접근 제어
2

주요 기능 구현

v1에서 완성한 핵심 기능 — 재고·Canister·업무·유해화학물질 기반 전체 구축

세션 인증
가입 → 관리자 승인 → 로그인. bcryptjs 해시. 비밀번호 초기화. plantScope 접근 제어
원·부재료 재고
Lot 단위 입고/출고. Lot 자동생성. 일괄 출고. 수불 날짜 퀵필터. 안전재고·경고% 이중 기준
Canister 관리
내용물·사이즈·위치·상태 동적 기준정보. 90% 무게 경고. 이력카드. 상태 즉시변경
합성 Batch 기록
Batch No. 기록 및 원·부재료 투입이력. FIFO 분배 출고
유해화학물질
관리대장(F13). 보관가능수량 초과 경고. 품목별 관리
업무(Task)
승인 워크플로. Task 신호등. 자동 지연 처리. 건의사항 게시판
재고 정합성 검사
Admin에서 수불 이력 기반 정합성 검사. 불일치 감지

기능 강화 · 인터락

운영 안정성을 위한 제약·연동 구조

파일 뮤텍스
테이블 단위 withLock. 동일 테이블 동시 쓰기만 직렬화, 다른 테이블은 병렬 허용
Canister 무게 인터락
사이즈별 최대무게 90% 초과 시 경고. Settings에서 동적 기준값 관리
안전재고 이중 기준
safetyStock(절대 수량) + warningPct(%) 두 조건 동시 적용. 품목별 개별 설정
공장 접근 제어
plantScope 미들웨어 레벨 차단 — API 직접 호출도 방어
FIFO 출고
입고일 기준 오래된 Lot부터 자동 분배. 수량 초과 시 다음 Lot 이월

버그 수정 · 원인 분석

v1 개발 중 발생한 주요 버그와 해결

start-server.bat 인코딩
한글 echo가 VDI에서 깨짐 → echo 영문 교체 + chcp 65001 선행
Canister 기준값 enum 오류
하드코딩 배열로 검증하다 동적 설정과 불일치 → Settings 기준값으로 전환
경고 재표시 오류
숨김 처리한 경고가 조건 변경 후 재노출 안 됨 → 조건 재평가 로직 추가
npm install 스크립트 오류
esbuild postinstall 권한 오류 → --foreground-scripts 플래그 적용

학습 · 기술 포인트

v1에서 익힌 핵심 기술 개념
