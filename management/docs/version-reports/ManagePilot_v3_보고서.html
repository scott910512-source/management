버전 컨셉 · 기술 배경

기능 강화 · 인터락

v3에서 추가된 데이터 신뢰성·보안 구조

🔧 진행 중 — Daily Report 경로 연동

VDI 환경에서 CMD의 네트워크 드라이브 접근 제한(보안 정책)으로 bat의 dir 명령 미작동. PowerShell Get-ChildItem으로 파일 검색 전환 예정. Task Scheduler 등록 후 매일 자동 실행 목표.

변경이력 자동 기록
Lot 수정·삭제 시 changelog 자동 삽입. 수동 조작 없이 감사 추적
재고 일치화
수불 역계산으로 불일치 감지 → 조정 수불 삽입으로 자동 정합
데모 이중 차단
클라이언트: 저장 버튼 비활성. 서버: demo 역할 저장 차단. 우회 불가
PS1 인코딩 안전화
한글 시트명을 Unicode code point로 처리 — ASCII-safe. 인코딩 환경 무관
파일명 키워드 자동 검색
*1공장*Daily*.xlsx 패턴 — 파일명·월 변경에도 수동 수정 불필요

버그 수정 · 원인 분석

v3 개발 중 발생한 주요 버그와 해결

소진 Lot 재입고 오류
잔량 0 Lot 재입고 시 중복 ID 충돌 → upsert 처리로 수량 누적
?new=1 퀵메뉴 미연결
SubMaterials ?new=1이 기존 모달로 연결 → ReceiveModal로 라우팅 수정
bat 경로 오류(공백)
공백 포함 경로 따옴표 미적용 → set 선언부 따옴표 제거, 실행 시 "%VAR%"로 감쌈
bat Unix LF 인코딩
bat 파일 Unix LF 저장 → Windows CMD 줄 인식 실패. UTF-8 CRLF 재저장
PS1 batch-yield 미인식
$BATCH_RE가 한글 "배치별.*수율"만 잡음 → 영문 "Batch.*원료 사용량" 패턴 추가
